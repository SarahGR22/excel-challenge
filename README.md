# excel-challenge
Module 1 Crowdfunding


Crowdfunding platforms like Kickstarter and Indiegogo have been growing in success and popularity since the late 2000s. From independent content creators to famous celebrities, more and more people are using crowdfunding to launch new products and generate buzz, but not every project has found success.

To receive funding, the project must meet or exceed an initial goal, so many organizations dedicate considerable resources looking through old projects in an attempt to discover “the trick” to finding success. For this Challenge, a database of 1,000 sample projects will be organize and analyze to uncover any hidden trends



For this module I worked with Heather and received feedback from both Mark and Ben.
